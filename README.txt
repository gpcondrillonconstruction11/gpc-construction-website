GP CONDRILLON CONSTRUCTION WEBSITE

Files:
- index.html (main website page)
- assets/ (company and project images)

To publish with GitHub Pages:
1. Open the repository created for this website.
2. Click Add file > Upload files.
3. Upload index.html, README.txt, and the entire assets folder (including all three PNG images).
4. Commit changes to the main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: /(root), then Save.
8. Wait for GitHub Pages to publish the website. The public link will appear in Settings > Pages.
